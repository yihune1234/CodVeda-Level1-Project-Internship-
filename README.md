# Event Manager – Smart Event Management System (SEMS)

A beautiful, modern, full-stack **Event Management System** built with pure **HTML, CSS, Vanilla JavaScript + Node.js/Express**  
Perfect for college fests, workshops, cultural events, seminars & more!

Live Demo: [https://your-event-manager.up.railway.app](https://your-event-manager.up.railway.app)  
(Replace with your actual link after deploying

## Features

- **Full CRUD Operations** (Create, Read, Update, Delete Events)
- **Stunning Modern UI** with Glassmorphism & Gradient Design
- **Dark / Light Mode Toggle** (with memory)
- **Responsive Design** – Works perfectly on mobile, tablet, desktop
- **Clean Card Layout** with hover effects and rainbow accent bars
- **Add, Edit, Delete Events** with smooth experience
- **Permanent Data Storage** using JSON file (no database needed)
- **100% Vanilla JS** – No React, No Frameworks (perfect for internships)

## Tech Stack

| Layer        | Technology                          |
|-------------|-------------------------------------|
| Frontend    | HTML5, CSS3, Vanilla JavaScript     |
| Backend     | Node.js + Express.js                |
| Data        | JSON file (`events.json`)           |
| Styling     | Custom CSS + Google Fonts (Poppins) |
| Deployment  | Railway / Render (Free & Permanent) |
